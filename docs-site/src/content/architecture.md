# 架构与边界

## 目录职责

- backend：Goravel 应用、认证、授权、HTTP 路由、GORM 连接和平台服务。
- admin：Vue 管理壳、路由、资源引擎、生成的 TypeScript API 客户端。
- modules：独立业务模块，包含后端能力、管理端页面、Manifest 和验收。
- plugins：平台插件，包含启停生命周期、依赖和运行时注册。
- contracts：OpenAPI、Schema 和生成输出。
- docs-site：独立的开发者文档站，只生成静态 HTML。

管理模块和插件页面是控制面。它们负责状态、版本、依赖、权限和配置入口。模块或插件注册的订单、商品、支付渠道等业务页面属于业务面，应显示为独立导航项。

## 依赖方向

业务模块和插件可以依赖平台核心与资源引擎，但平台核心不能反向依赖某个业务模块。管理端业务页面不能直接调用 fetch 或 axios，应通过生成的客户端和 ResourceDataProvider。

## 运行时注册

模块启动时挂载菜单、路由和资源。插件启用时执行 setup 并挂载注册结果，停用时执行 teardown 并清理 owner 所有的动态注册。导航保持扁平注册，侧边栏根据入口数量自动决定一级菜单或可折叠分组。

# Go Vue Admin 开发者文档

Go Vue Admin 是一个面向业务后台的模块化平台，组合了 Goravel 后端、Vue 3 管理端、资源引擎、GORM 数据层、插件运行时和 OpenAPI 契约。

这份文档面向需要开发模块、插件、资源和外部集成的开发者。后台管理面板不会加载这个站点，文档也不会参与后台生产构建。

## 从这里开始

- 快速开始：启动本地后端和管理端，了解默认配置。
- 架构与边界：理解 backend、admin、modules、plugins 和 contracts 的职责。
- 开发业务模块：从模块 Manifest 到菜单、路由、资源和验收。
- 开发平台插件：了解启停生命周期、依赖和运行时注册。

## 稳定开发边界

OpenAPI 文档和 Schema 是接口契约的机器可读来源。生成客户端时不要直接编辑生成文件；业务页面通过生成的客户端和 ResourceDataProvider 使用接口。

生产部署前请阅读生产级检查清单。当前项目已经具备 Foundation 基础能力，但仍需要结合你的业务补齐密钥管理、备份、监控、限流和灾备。
